SIRIUS INTERFEROMETRY ANALYSIS SCRIPTS
Date: Jan 5, 2026
Author: Roshawn Marcell Valentino Terrell

DESCRIPTION:
These Python scripts were used to process archival VLT/GRAVITY data (ESO) 
for the paper "Interferometric Detection of a Persistent Closure Phase Anomaly 
in the Sirius System."

FILES:
1. Scan_The_System.py - Scans .fits files for Phase and Visibility metrics.
2. Plot_Discovery.py - Generates the comparative Phase Plot (Sirius A vs Control).

REQUIREMENTS:
- Python 3.x
- Libraries: astropy, numpy, matplotlib

INSTRUCTIONS:
Place these scripts in the same directory as the .fits data files downloaded 
from the ESO Archive (GRAVITY, Jan 20, 2021). Run via terminal.
